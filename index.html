Test automation that reads like English

Why qavajs

Everything a test framework needs, already wired up

Stop gluing tools together. Start testing.

Plain-English tests

Write scenarios in Gherkin from hundreds of ready-made steps. Anyone on the team can read — and write — them.

Learn more →

Page object engine

Describe your UI once and reference elements by alias like "Header > Login Button". Selectors stay out of tests.

Learn more →

Memory & data

Resolve '$values' at runtime, compute dynamic data and override any value from the CLI for every environment.

Learn more →

Any driver

Playwright, WebdriverIO or Cypress — for web and native mobile. Switch engines without rewriting scenarios.

Learn more →

Scale in CI

Parallel workers, sharding, retries and tag filters out of the box. Drop it into any pipeline.

Learn more →

Reports that matter

HTML, JUnit, ReportPortal and Xray formatters, plus an interactive UI mode to debug runs live.
